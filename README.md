# Nakoda Creative Studio website

## Files
- `index.html` — page content and structure
- `style.css` — desktop and mobile styling
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/` — reserved for approved NCS logo and original portfolio images

## Upload to GitHub
Upload `index.html`, `style.css`, and `script.js` to the root of your existing website repository (the same folder where your current `index.html` is located). Keep the filenames exactly as shown.

The page currently uses remote Unsplash image URLs as illustrative visuals. Replace these with original, approved client artwork before presenting them as completed portfolio projects.

## Enquiry form
The form opens a pre-filled WhatsApp message to `+91 98900 53179`. It does not save submissions on a server. Terms acceptance is included in the generated message.

## Before launch
- Check the site on mobile and desktop.
- Replace illustrative portfolio images with approved work.
- Verify social profile links and legal policy pages.
- Keep existing domain DNS and email records unchanged.


## Brand logo
`assets/nakoda-logo.png` is the supplied Nakoda Creative Studio logo, cropped for use in the site header and footer. Upload the `assets` folder along with the HTML, CSS and JS files.
